# Architecture Decision Records

Each ADR records a decision about how this library is built and maintained: the context, the options considered, and what was chosen and why. See [ADR-0001](0001-record-architecture-decisions.md) for the format.

These ADRs will move into AIGF's ADR series when this library is rolled into AIGF, and will be renumbered then.
